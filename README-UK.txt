NORYVIO — BREW & BLOOM 2.0 / ІНТЕРАКТИВНИЙ БАГАТОСТОРІНКОВИЙ ДЕМОСАЙТ

1. Розпакуй ZIP у C:\Projects\noryvio-v2 із збереженням структури папок.
2. Виконай npm run dev, відкрий http://localhost:4321/demo/coffee/
3. Виконай npm run build та пройди всі маршрути.

СТОРІНКИ
/demo/coffee/           головна
/demo/coffee/menu/      інтерактивне меню: пошук, фільтр, сортування, додавання в кошик
/demo/coffee/about/     історія/цінності
/demo/coffee/events/    події
/demo/coffee/gallery/   галерея з фільтрами й lightbox
/demo/coffee/contacts/  контакти й форма демобронювання
/demo/coffee/checkout/  кошик, зміна кількості, підсумок і демонстраційне оформлення

ДАНІ / ІНТЕГРАЦІЯ
- Меню: src/data/coffeeMenu.ts (усі позиції й ціни — умовні).
- Спільна оболонка: src/components/demos/coffee/CoffeeLayout.astro
- Стилі: src/styles/demos/coffee.css
- Сторінки: src/pages/demo/coffee/*.astro
- Локальний preview.webp: public/images/demos/coffee/preview.webp
- Фото контенту використовують images.unsplash.com. Для повністю офлайн-режиму замінити URL на локальні фото з ліцензією.
- Google Fonts так само потребує інтернету; є системні fallback-шрифти.
- Кошик зберігається тільки у браузері (localStorage).
- Бронювання та оформлення — виключно локальні демонстрації, дані не надсилаються нікуди, платіжні системи відсутні.
- Сайт навмисне позначений noindex,nofollow і не містить вигаданих реальних телефонів, адрес, відгуків.
- Переходи Noryvio: /templates/ та /#contacts. Якщо твої маршрути змінені, зміни посилання в CoffeeLayout.astro.

ПЕРЕВІРКА
- Переходи між сімома маршрутами
- Фільтри та пошук меню, різні сортування
- Додати 2 різні товари в кошик, змінити кількість, перевірити підсумок; оновити сторінку — кошик має зберегтись
- Оформити демозамовлення — не повинно бути реального запиту в мережу
- Форма бронювання (обов'язкові поля, дата, згода)
- Галерея (фільтр, lightbox, Escape)
- Mobile header і верстка на 360, 390, 768, 1440 px; reduced motion

ВАЖЛИВО: це демонстраційний концепт, не робочий сервіс кав’ярні: для реальних бронювань/замовлень треба бекенд, захист і юридичні документи.
